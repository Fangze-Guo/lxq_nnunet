## lxq_nnunet 🧠
📌 基于 nnU-Net V2 的医学图像分割工具，自动适配数据集的端到端解决方案。

✨ 核心特点

- 全自动配置：无需专家知识，自动分析数据集并生成最优 U-Net 分割 pipeline

- 多场景支持：处理 2D/3D 图像、多模态数据，兼容不同分辨率与体素尺寸

- 增强功能：支持稀疏标注学习、区域训练、预训练与微调等进阶功能

- 性能升级：新增残差编码器预设，提升分割精度（适配多种 GPU 内存）

- 易用性：V2 版本全面重构，代码更清晰，集成与扩展更简单

分割预训练模型：https://huggingface.co/Xunqi/nnunet_segment_model/tree/main
